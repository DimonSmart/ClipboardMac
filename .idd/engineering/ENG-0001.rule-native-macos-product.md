# ENG-0001.rule-native-macos-product

## Rule

Implement the MVP as an independent Swift and AppKit native macOS application
with macOS 26 as its minimum supported system.

## Applicability

Always

## Rationale

The approved product direction requires native macOS behavior and an independent
codebase; Maccy is technical reference material only.

## Guidance

- Do not fork, copy, or make the product depend on Maccy source code.
- Support Apple Silicon and Intel configurations when the active toolchain and
  compatible hardware permit.
- Use availability handling for APIs newer than the deployment target.

## Verification

Source and dependency review shows an independent Swift and AppKit application
with the documented deployment target and no Maccy-source dependency.
