# IDD-0006.spike-real-device-paste-validation

A spike is active research only while the question is unresolved. When resolved,
move durable product behavior into a spec, move durable architecture decisions
into an ADR, and delete the spike unless it remains useful as active research.

## Question

Can a minimal macOS 26 implementation open a history panel by global shortcut,
preserve the prior paste target, respect clipboard privacy, and safely issue one
normal paste into Notes or TextEdit and VS Code?

## Constraints

- Test on real macOS 26 hardware with clipboard and Accessibility permission
  states recorded.
- Do not use a global keyboard hook or bypass macOS permissions.
- Treat an unreliable target restore as a Copy Only outcome.

## Method

- Build the smallest native prototype needed to capture target context, display
  a panel, prepare plain text on the clipboard, and attempt one normal paste.
- Exercise normal and alternate keyboard layouts and record target, permission,
  and fallback observations without recording clipboard content.

## Result

Not yet investigated.

## Recommendation

Complete this spike before building the full panel. If safe automatic insertion
cannot be established, revisit the paste design before proceeding with UI work.
