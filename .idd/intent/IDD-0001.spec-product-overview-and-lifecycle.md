# IDD-0001.spec-product-overview-and-lifecycle

## Intent

Clipboard History is a native macOS menu-bar utility for macOS 26 and later. It
keeps a local history of copied plain text, lets the user find and select an
earlier entry, and makes the selected text available for insertion into the
field that was active before the history panel opened.

## Related Specifications

- IDD-0002 defines capture, clipboard privacy, and source exclusion.
- IDD-0003 defines retained history and search semantics.
- IDD-0004 defines the panel, commands, and settings.
- IDD-0005 defines automatic paste and its safe fallback.
- IDD-0006 validates the critical paste interaction on real devices.

## Behavior

- The application runs as a menu-bar utility without a persistent Dock icon or
  ordinary main window. Its menu offers Open History, Pause or Resume Capture,
  Settings, Clear Recent History, and Quit.
- It permits one active instance and one capture monitor. Opening it again
  activates the existing instance or history panel when supported by packaging.
- Capture starts after required clipboard access is available. While paused, the
  application neither reads clipboard content nor records history; resuming
  starts from the then-current clipboard change and does not import content
  copied during the pause.
- The supported MVP scope is plain-text history, search, pins, deletion and
  clearing, source exclusions, launch at login, menu-bar control, configurable
  global hotkey, local storage, automatic paste, and Copy Only.
- Images, files, rich-text formatting, cloud or device sync, OCR, AI features,
  templates, collections, editing saved entries, import/export, global keyboard
  monitoring, and macOS versions before 26 are outside the MVP scope.
- History data and clipboard content remain local. The application sends neither
  content nor telemetry to external services and does not log text content.
- Launch at Login is off until the user enables it. The shown state reflects the
  system login-item state.
- The About dialog shows the installed version, checks the project's public
  GitHub Releases for a newer stable version, and lets the user install that
  release and restart the application. If checking or installation is
  unavailable, the dialog explains the state and provides the release page when
  one is available.
- Update checks send only standard HTTP metadata requests to the project's
  public GitHub repository. Clipboard contents, history, and usage data are
  never sent; update checks do not depend on clipboard permissions.

## Product-Significant Architecture And Constraints

- The product supports Apple Silicon and Intel Macs that can run macOS 26.
- Clipboard data is stored in the current user's app-specific Application
  Support directory and must not be made accessible to other ordinary users.
- The product does not claim application-level encryption and must not
  automatically synchronize its history through iCloud Drive.

## Non-goals

- The product does not guarantee capture of every clipboard change.
- It does not claim that hidden, protected, or remote applications will accept
  synthetic paste events.

## Acceptance Criteria

- A user can copy text in a permitted app, open history, select an earlier item,
  and have it inserted into the original field when the paste target is safe.
- Pins, history, and user settings survive app and system restarts.
- The app remains usable for browsing saved history and Copy Only when
  Accessibility permission is unavailable.
- About identifies whether the installed version is current or a newer stable
  release is available; installing an available update replaces the app and
  relaunches the updated version.

## Verification

- Verify the critical workflow in a text editor, browser form, code editor, and
  terminal-like application on a real macOS 26 system.
- Verify the menu-bar lifecycle, restart persistence, privacy behavior, and
  denied-permission paths without exposing clipboard content in diagnostics.
- Verify About against current, newer, prerelease, and unavailable release
  metadata, plus update download, installation, and relaunch outcomes.
